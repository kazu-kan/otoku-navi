# おトクナビ

三井住友カード ゴールド（NL）の「スマホのタッチ決済で7%還元」と、メットライフのクラブオフを使いこなすための、自分専用のスマホアプリ（ホーム画面に追加して使うWebアプリ）です。

## できること

| 画面 | できること |
|---|---|
| 📍 探す | 現在地や行き先（例: USJ、梅田、京都駅）の近くにある7%還元のコンビニ・飲食店を地図と一覧で表示。行き先を検索すると、その地域向けのキャンペーンやクラブオフの優待へのリンクも表示。よく使うクラブオフ優待店を登録すると地図に出る |
| 💳 払い方 | お店と金額を選ぶと「どう払うのが一番おトクか」とポイントの目安を表示。1万円超え（タッチ決済できない）、Android＋Mastercard（Google Pay非対応）、スターバックス（アプリ経由のみ）なども自動で注意 |
| 🎁 キャンペーン | 受付中のキャンペーン一覧。エントリー要否・締切までの日数・地域限定を表示。「エントリーした」「関係ない」を付けて整理できる |
| 📈 100万円 | Vpassの明細CSVを読み込んで、年間100万円（翌年以降の年会費無料＋毎年10,000pt）の達成ペースを表示。7%対象店での利用額、Vポイントの有効期限も表示 |
| 🔔 通知 | 毎朝8時ごろに自動でチェックして、スマホに通知。①新しいキャンペーン ②エントリーが必要なキャンペーンの開始日・締切前日 ③7%対象店の追加・削除 |

## はじめのセットアップ（1回だけ・20分くらい）

スマホで外出先から使えるように、無料の「GitHub」にアプリを置きます。

### 1. GitHubにアプリを置く

1. https://github.com/signup で無料アカウントを作る
2. 右上の「＋」→「New repository」
   - Repository name: `otoku-navi`
   - **Public** を選ぶ（無料で公開ページを作るため。個人のデータは入らないので大丈夫です → 下の「知っておいてほしいこと」参照）
   - 「Add a README file」はチェックしない
   - 「Create repository」
3. 表示された画面の「uploading an existing file」をクリック
4. PCの `お得アプリ` フォルダから、次の4つをまとめてドラッグ＆ドロップ
   - `docs` フォルダ
   - `monitor` フォルダ
   - `.github` フォルダ
   - `README.md`
   - ※「★通知の設定メモ」と「PCで試す.bat」は**上げない**
5. 下の「Commit changes」を押す

> `.github` フォルダがうまく上がらなかったとき: リポジトリの画面で「Add file」→「Create new file」→ ファイル名の欄に `.github/workflows/monitor.yml` と入力し、PCの `.github\workflows\monitor.yml` の中身をメモ帳で開いて貼り付け →「Commit changes」

### 2. 公開ページを作る

1. リポジトリの「Settings」→ 左の「Pages」
2. 「Source」を **Deploy from a branch**、「Branch」を **main**、フォルダを **/docs** にして「Save」
3. 1〜2分待って再読み込みすると、上に `https://（ユーザー名）.github.io/otoku-navi/` と表示されます。これがアプリのURLです

### 3. 通知の設定

1. リポジトリの「Settings」→ 左の「Secrets and variables」→「Actions」→「New repository secret」
   - Name: `NTFY_TOPIC`
   - Secret: 「★通知の設定メモ」に書いてあるトピック名
   - 「Add secret」
2. スマホに無料アプリ **ntfy** を入れる（App Store / Google Play）
3. ntfyアプリで「＋」→ トピック名に同じ文字列を入れて購読
4. リポジトリの「Actions」タブ →（「I understand my workflows...」のボタンが出たら押す）→ 左の「キャンペーン監視」→ 右の「Run workflow」→ 緑の「Run workflow」
5. 1〜2分後、スマホに「おトクナビ 通知を開始しました」と届けば成功。以後は毎朝自動で動きます

### 4. スマホのホーム画面に追加

- **iPhone**: SafariでアプリのURLを開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」
- **Android**: Chromeで開く → 右上の「︙」→「ホーム画面に追加」または「アプリをインストール」

最初に「探す」で「現在地」を押すと位置情報の許可を聞かれるので「許可」してください。右上の⚙で、スマホの種類とカードのブランド（Visa / Mastercard）を確認しておくと、払い方の判定が正確になります。

## 使い方のコツ

- **お店に入る前**: 「探す」→ 近くの緑の点が7%のお店。一覧の「払い方」を押すと、そのお店での払い方がすぐ出ます
- **おでかけ前**: 「探す」で行き先を検索。その地域のキャンペーン（例:「関西限定 タッチ決済乗車で最大20%還元」）と、クラブオフで宿・レジャーを探すボタンが出ます
- **クラブオフの優待店**: 公式サイト・公式アプリで探して、よく行くお店だけ「＋登録」。地図を動かしてお店を真ん中に合わせてから登録すると位置が正確です
- **100万円**: 月1回、Vpass（ブラウザ版）の「ご利用明細」からCSVをダウンロードして読み込み。同じ月を何度読み込んでも二重に数えません。最初に集計開始月（右上）を設定してください
- **機種変更の前**: ⚙ →「書き出す」でバックアップ。新しいスマホで「読み込む」

## 知っておいてほしいこと

- **個人のデータはスマホの中だけ**: 明細・登録したお店・チェックは、そのスマホのブラウザの中だけに保存され、どこにも送られません（GitHubにも上がりません）。GitHubで公開されるのは、アプリのプログラムと公開情報（キャンペーン一覧・対象店）だけです
- **通知の元は三井住友カードのプレスリリース（PR TIMES）**です。Vpassの会員ページだけで告知されるキャンペーンは拾えないことがあるので、月に1回くらいはVpassアプリのキャンペーン一覧も見てください
- **地図のお店は OpenStreetMap のデータ**です。登録されていないお店もあります
- **クラブオフは自動取得しません**。ログインが必要な会員サイトで、自動取得は規約違反やアカウント停止のおそれがあるためです
- 還元率・対象店は2026年9月時点の公式情報がもとです。大きな買い物の前は公式ページで確認してください。学習・情報整理のためのツールで、還元を保証するものではありません
- 自動チェックが失敗すると、GitHubからメールが届きます。GitHubは60日間まったく動きがないリポジトリの定期実行を止めますが、このアプリは毎日データを更新するので通常は止まりません。万一止まったら「Actions」タブで有効にし直してください

## 7%の対象店が増えたとき

「🏪 7%還元の対象店が変わりました」という通知が来たら、`docs/data/chains.json` に新しいチェーンを追加すると地図検索に出るようになります（キャンペーン画面の下にも「アプリ未対応の新しい対象店」として表示されます）。追加作業はAIに「chains.jsonに○○を追加して」と頼めばできます。アプリのファイルを変えたときは、`docs/sw.js` の `VERSION` の数字を1つ上げてからGitHubに上げ直してください（スマホに古い版が残らないようにするため）。

## フォルダの中身

```
お得アプリ/
├─ docs/                  アプリ本体（GitHub Pagesで公開される）
│  ├─ index.html / style.css / app.js
│  ├─ data/chains.json     7%対象チェーンの一覧
│  ├─ data/campaigns.json  キャンペーン一覧（毎朝自動で更新される）
│  ├─ manifest.webmanifest / sw.js / icons/   ホーム画面に追加するための設定
├─ monitor/monitor.py     毎朝キャンペーンを確認して通知するプログラム
├─ .github/workflows/monitor.yml   毎朝8時に上のプログラムを動かす設定
├─ PCで試す.bat           PCのブラウザで試す（Pythonが必要）
└─ ★通知の設定メモ（アップロードしない）.txt
```
