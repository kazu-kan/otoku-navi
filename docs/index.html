        このアプリについて

        還元率・対象店は三井住友カードの公式ページ（2026年9月時点）をもとにしています。条件は変わることがあるので、大きな買い物の前は公式ページで確認してください。地図とお店のデータは OpenStreetMap を使っています（未登録のお店もあります）。学習・情報整理のためのツールで、還元を保証するものではありません。

        クラブオフ優待店を登録

        地図を動かしてお店の位置を真ん中に合わせてから登録すると正確です。

        通知の受け取り方

        1. スマホに無料アプリ「ntfy」を入れる（App Store / Google Play）
        2. アプリで「＋」→ トピック名に、セットアップ時に決めた通知用トピック名を入力して購読
        3. 毎朝8時ごろに新着キャンペーンをチェックし、見つかったら通知が届きます。エントリーが必要なものは「開始日」と「締切の前日」にも通知します

        トピック名は、PCの「お得アプリ」フォルダにある「★通知の設定メモ」に書いてあります。
